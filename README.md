# PruebasVarias

Repositorio de pruebas varias.

## uber.py

App de [Streamlit](https://streamlit.io) que carga 10.000 registros de recogidas de Uber en Nueva York (septiembre 2014) y muestra:

- Los datos en bruto (opcional, con una casilla).
- Un histograma de recogidas por hora.
- Un mapa con las recogidas de la hora elegida en un slider.

### Ejecutar

```bash
pip install streamlit pandas numpy
streamlit run uber.py
```
